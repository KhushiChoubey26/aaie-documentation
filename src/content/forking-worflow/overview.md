# Forking Workflow

This folder contains documentation related to the forking workflow and contribution process for the AAIE project.

## Overview

The forking workflow is the standard process for contributing to the AAIE project. It ensures that all changes go through proper review and approval before being merged into the main repository.

## Key Components

- **Contribution Overview**: Basic guidelines for contributors
- **Repository Structure**: Understanding the project organization
- **Folder Structure Policy**: Rules for organizing content
- **Contributor Workflow**: Step-by-step contribution process
- **PR Review Process**: How pull requests are reviewed
- **Guidelines and Enforcement**: Standards and compliance

## Getting Started

If you're new to contributing, start with the [Contribution Overview](./contribution-overview) document to understand the basics of the workflow.
